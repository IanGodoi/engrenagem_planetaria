# **Engrenagem Planetária no FreeCAD**



Projeto de uma caixa de engrenagens planetárias desenvolvido no FreeCAD.



O objetivo do projeto é modelar manualmente o sistema de engrenagens, incluindo a engrenagem solar, engrenagens planetárias e coroa.



### Software utilizado



\- FreeCAD



### Arquivo principal



`engrenagem\_planetaria.FCStd`



### Desenvolvimento



O projeto envolveu:



\- criação das engrenagens;

\- definição da quantidade de dentes;

\- cálculo dos ângulos entre os dentes;

\- utilização de Sketches;

\- criação dos dentes;

\- utilização de Pad;

\- utilização de Polar Pattern para repetição dos dentes;

\- posicionamento das engrenagens planetárias;

\- correção de interferências entre os dentes;

\- montagem final do sistema planetário.



### Estrutura do sistema



O conjunto é formado por:



\- engrenagem solar;

\- engrenagens planetárias;

\- coroa externa;

\- posicionamento dos planetários ao redor da engrenagem solar.



### Objetivo



Este projeto foi desenvolvido como parte dos estudos de modelagem mecânica e robótica utilizando o FreeCAD.
